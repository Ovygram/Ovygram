# VLESS для проверки SDK 3

Импортируйте сборку `vless_test.ovyzip` для своей ОС и включите плагин. Закройте менеджер плагинов.
В главном меню Ovygram откройте **VLESS · подключение**, вставьте ссылку `vless://` либо HTTPS-ссылку
на подписку и выберите сервер. После сообщения «Xray готов» откройте **Настройки прокси → Прокси
плагинов** и выберите `vless_test`. Для отключения нажмите **Отключить** в том же окне.
Кнопка **Остановить Xray** в настройках плагина также завершает движок.

Профили и пароли SOCKS5 действуют в пределах сеанса. Подписка читается по запросу, поддерживаются
строки VLESS и списки в Base64. Пример обрабатывает TCP/RAW, WebSocket, gRPC, HTTPUpgrade и XHTTP,
а также TLS и REALITY. Для Linux сетевая песочница требует Landlock ABI 6.

Для упаковки скачайте `Xray-windows-64.zip` либо `Xray-linux-64.zip` из релиза Xray-core v26.11.9.
Выполните `python pack.py ПУТЬ_К_ZIP КАТАЛОГ_РЕЗУЛЬТАТА`. Скрипт проверит SHA-256 и включит
в архив бинарник для выбранной ОС, лицензию и ссылку на исходники.
