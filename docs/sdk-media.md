# Медиа, файлы и плеер

Методы модуля `desktop.media` выполняются асинхронно. Создавай задачи через `self.run_async(...)`. Чат и аккаунт передаются явно, в том числе при работе из фонового аккаунта.

## Отправка медиа

| Вызов | Содержимое |
| --- | --- |
| `send_photo(chat, path, caption="")` | Фото с подписью |
| `send_voice(chat, path, duration=seconds, waveform=None)` | Готовый голосовой файл Ogg/Opus. Можно передать форму волны в формате Telegram |
| `send_video_note(chat, path, duration=seconds, size=pixels)` | Видеокружок из готового квадратного MP4 |
| `send_album(chat, items)` | От 2 до 10 фото и видео с индивидуальными подписями |
| `send_file(chat, path, caption="")` | Документ |

У всех операций отправки есть аргументы `progress` и `silent`. Файлы подготавливает плагин. Для обычного видео в альбоме нужны длительность в секундах, ширина и высота в пикселях. SDK загружает файлы, запрашивает у Telegram ссылки на элементы и отправляет весь альбом одной операцией. При ошибке до финальной операции в чат ничего не публикуется. При отмене или обрыве связи во время финального запроса проверь чат перед повтором. В альбоме прогресс отсчитывается для каждого файла отдельно.

```python
from desktop import media

await media.send_album(chat, [
    media.AlbumItem(photo_path, caption="Обложка"),
    media.AlbumItem(video_path, kind="video", duration=6.5, width=640, height=360),
])
```

## Выбор файла пользователем

`await media.pick_file(account)` открывает системный выбор файла от имени Ovygram и указывает в заголовке идентификатор запросившего плагина. Отмена возвращает `None`. После подтверждения SDK возвращает путь к копии файла в каталоге данных установки для указанного аккаунта. Плагин может обработать копию, послать её в чат или удалить.

Клиент открывает выбранный файл для чтения. Плагин получает данные порциями по 256 КиБ без исходного пути. Дескриптор привязан к установке и сеансу, освобождается по завершении, выгрузке или истечении срока бездействия. Пока открыт системный диалог, доступ плагинов к его виджетам и событиям приостановлен. Методы чтения принимают выданный клиентом токен. Источником данных служит тот же открытый файл на протяжении всего копирования.

## Штатная очередь загрузок

`await media.downloads(account)` возвращает видимые записи очереди выбранного аккаунта. Поля записи — `chat_id`, `message_id`, `started`, `transferred`, `size` и `done`. Размеры указаны в байтах. Пути пользователя остаются в клиенте. Передай запись в `await media.cancel_download(account, entry)`, чтобы отменить её. Если запись завершилась или была заменена другой загрузкой, метод вернёт `False`.

## Позиция и управление воспроизведением

`await media.playback(account, "song")` возвращает текущую позицию музыкального трека. Значение `"voice"` выбирает голосовое сообщение или видеокружок. Результат равен `None`, когда в выбранной категории нет текущего трека со считываемым состоянием для этого аккаунта.

Снимок содержит `kind`, `chat_id`, `message_id`, `document_id`, `position_ms`, `duration_ms`, `playing` и `buffering`.

```python
state = await media.playback(chat.account_id, "song")
if state:
    await media.control_playback(chat.account_id, state, "seek", position_ms=30_000)
```

Доступные команды — `play`, `pause`, `stop`, `next`, `previous` и `seek`. При смене аккаунта или трека устаревшая команда завершается ошибкой. Позиция ограничивается длительностью трека.
