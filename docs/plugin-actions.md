# Именованные действия

Модуль `desktop.actions` связывает обработчик с кнопкой, пунктом меню, сочетанием клавиш, треем и локальной ссылкой Ovygram. Вызов `register` асинхронный. Клиент проверяет имя и сочетание и отвечает до того, как плагин получит объект действия.

```python
from base_plugin import BasePlugin
from desktop import actions, media, ui

class ImportPlugin(BasePlugin):
    def on_plugin_load(self):
        self.run_async(self.setup())

    async def setup(self):
        self.import_file = await actions.register(
            "import-file", "Импорт файла", self.open_file,
            shortcut="Ctrl+Alt+I", tray=True, global_shortcut=True, link=True,
        )
        self.import_file.add_menu("main")
        self.log(self.import_file.link)

    async def open_file(self, invocation):
        if not invocation.account_id:
            ui.show_dialog("Сначала выберите аккаунт через меню плагина.")
            return
        path = await media.pick_file(invocation.account_id)
        if path is not None:
            self.log(f"Выбран файл {path.name}")
```

| Вход | Что получает плагин |
| --- | --- |
| `action.add_menu("chat")` | `Invocation` с источником `chat`, аккаунтом и чатом. Доступны также `main`, `profile`, `message`. Для меню сообщения передаётся само сообщение. |
| `ui.Button("Импорт", on_click=action)` | Источник `button`. Кнопка на собственной странице может передать `actions.Invocation("button", chat.account_id, chat)`, если ей известен чат. |
| `shortcut="Ctrl+Alt+I"` | Источник `shortcut`. Сочетание работает в окне Ovygram. Занятое другим действием или клавиатурным правилом сочетание вызывает ошибку регистрации. Штатные сочетания Telegram сохраняют свой приоритет. |
| `tray=True` | Пункт в системном трее. Источник `tray`, аккаунт активного основного окна, если он доступен. |
| `link=True` | Локальная ссылка в `action.link`. Ovygram показывает имя действия и идентификатор установки и передаёт плагину событие `link` после подтверждения. Ссылка действует на этой установке. Для вызова из другой программы Ovygram должен быть зарегистрирован системным обработчиком `tg://`. |
| `global_shortcut=True` | Пользователь выбирает сочетание через пункт «Сочетание» в трее или через `await action.configure_shortcut()`. Событие `global_shortcut` приходит, в том числе когда Ovygram в фоне. Плагину передаётся только вызов действия. |

При локальном сочетании клавиш `account_id` пуст. Если обработчик выполняет операцию с аккаунтом, покажите выбор через `client.accounts()` или используйте привязанный к чату элемент. Плагину, работающему с несколькими аккаунтами, следует передавать полученный аккаунт дальше вместе с чатом.

## Системные сочетания

Пользователь нажимает «Записать» в защищённом окне Ovygram и вводит сочетание из 2–4 клавиш. Если сочетание уже занято другим действием плагина или задано для push-to-talk, клиент предлагает выбрать другое. Кнопка «Сбросить» убирает привязку. Выбор сохраняется для пары из идентификатора установки и имени действия в профиле клиента. Глобальные сочетания используют тот же механизм платформы, что и push-to-talk. Их доступность зависит от ОС и рабочего окружения. `configure_shortcut()` возвращает `False`, если клиент не может показать окно или ОС не разрешает сочетания.

Пока Ovygram заблокирован, пункты плагинов скрыты в трее, активация сочетаний и подтверждение ссылки приостановлены. При удалении действия и выгрузке плагина клиент освобождает его активные привязки. Старое подтверждение ссылки или отложенное нажатие в трее не вызывает новое действие после переустановки.

Во время установки плагина или системного выбора файла встроенные вызовы действий и настройка сочетаний приостановлены.

## Жизненный цикл

Имя содержит от 1 до 48 символов и начинается с латинской строчной буквы. Далее допустимы латинские строчные буквы, цифры, точка, дефис и подчёркивание. Оно уникально в пределах установки. Разные экземпляры одного плагина могут использовать одинаковое имя. `action.remove()` снимает регистрацию и связанные через `add_menu` пункты. Ручная кнопка плагина управляет своим отображением через API своей страницы.
