# Исправления интерфейса плагинов — 15 ноября 2026

Исходная ветка: `fix/plugin-ui-startup-updates`. Изменения слиты в `main`.

## Реализовано в исходниках

- Установка: нативная панель Telegram с действием и отменой рядом внизу
  справа; высота по содержимому и прокрутка длинного описания. Новая версия
  и каждый установленный экземпляр разделены собственными широкими карточками.
- Статусы: проверенный плагин зелёный, официальный синий; цвета сохраняют
  смысл в ночных темах и при смене акцента. Непроверенный остаётся приглушённо
  красным.
- Настройки: ширина обновляется до показа новой секции, без старого узкого
  кадра анимации; исправлена высота строк с переключателем и действиями.
  Наведение мягко выделяет текст действия, а не всю прямоугольную область;
  переключатель не получает фон строки.
- Запуск: включённые плагины загружаются после подключения нативного
  диспетчера. Регистрация меню из `on_plugin_load` больше не опережает
  подключение Desktop API. Повторное подключение не запускает плагин дважды.
- Проверка обновлений: видны выполнение и результат, включая отсутствие новых
  версий и настоящую причину ошибки; обновление доступно прямо в карточке.
  Фоновые проверки сохраняют прежний график по половинам календарного дня.
- Уведомление об обновлениях использует штатный баннер над списком чатов.
  Оно приоритетнее дня рождения; уведомление о непроверенном входе в аккаунт
  сохраняет более высокий приоритет. Крестик скрывает известные версии до
  появления другой новой версии, в том числе после перезапуска. Нажатие
  открывает настройки плагинов. Установка обновления требует действия пользователя.

## Выполненная проверка

Полный набор SDK на CPython 3.13.5:

```sh
python3.13 -m unittest discover -s tools/ovygram/tests
```

176 тестов: 174 прошли, 2 пропущены из-за отсутствия собранного нативного
хоста. Новые проверки воспроизводят регистрацию меню при запуске, итог
проверки после очистки очереди уведомлений, перезапуск со скрытым баннером,
появление следующей версии и ручную замену уже обновляемого экземпляра.
Сетевой транспорт реестра в этих тестах поддельный; ответы подписываются
тестовым ключом Ed25519. `git diff --check` проходит. Использованные API UI
сверены с закреплённой версией `lib_ui`; ссылка на подмодуль не менялась.

## Ожидает отдельной разрешённой сборки

Клиент, нативный хост и GitHub Actions не собирались и не запускались.
Существующий Windows exe этими коммитами не заменяется. После сборки нужно
проверить визуально установку/обновление с длинными описаниями, ночные темы,
масштаб 125%, первое открытие настроек, наведение и соседство баннера с днём
рождения. Проверка исходников и Python-тесты не заменяют эти проверки.
